System Architecture & Model Disclosures

Technical specifications and scientific integrity statement

Model Resolution:

The ML calibration ensemble predicts at district scale (~25km IMD grid). Place-name geocoding via OpenStreetMap resolves village and block coordinates, which map to the corresponding district meteorological envelope. Local hyper-recent context is supplemented with Open-Meteo live API.

Decision Layer Architecture:

The decisionEngine() translates multi-target probabilistic forecasts into actionable agronomic decisions (SOW / WAIT / PROTECT) using ICAR crop stage calendars and moisture thresholds without mutating raw ML weights.

WhatsApp Gateway:

Runs on Twilio WhatsApp Sandbox connected to FastAPI webhook with stateful intake and Groq/Anthropic tone personalization grounded strictly in calibrated forecast outputs.
